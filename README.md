# ЗП Твиглс: калькулятор зарплаты менеджеров

Мобильный сайт для менеджеров отдела продаж: вносят продажи по тарифам и выручку по неделям, сайт считает ЗП по ставкам. Цифры сохраняются в Google-таблице «ЗП менеджеров: база» через Apps Script, поэтому не меняются от смены браузера.

Сайт открывается по паролю. В репозитории лежат только страница входа `index.html` и зашифрованное приложение `app.enc.json` (PBKDF2 + AES-GCM). Код, ставки, данные и адрес Google-скрипта внутри шифра. Открытого исходника в репозитории нет.

## Публикация на GitHub Pages

Settings → Pages → Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml` сам публикует сайт после каждого коммита в `main` (запускает тесты и выкладывает `index.html` и `app.enc.json`). Сайт будет по адресу `https://twiglles.github.io/zp/`.
